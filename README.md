# Pooja Gosika: portfolio

Next.js, TypeScript, Tailwind CSS 4 and Motion, built as a static site.

## Run it

```
npm install
npm run dev
```

Then open http://localhost:3400.

## Change the content

Every word on the site is in `src/data/site.ts`. Project screenshots are in
`public/work`, logos in `public/logos`, the profile photo is
`public/pooja.jpg`, and the header covers are `public/cover.webp` (light
theme) and `public/cover-dark.webp` (dark theme).

## Deploy

`npm run build` writes the finished site to the `out` folder. On Render
(Static Site):

- Build command: `npm install; npm run build`
- Publish directory: `out`

## What updates when

- The GitHub contribution grid is read from GitHub when the site is built, so
  it is as fresh as the last deploy. Redeploy to refresh it.
- The visitor map works in the visitor's browser. It shows where that visitor
  is and draws a line to Hyderabad. Nothing is stored.

The world map shapes are generated by `npm run world` into
`src/data/world.json`. It only needs to be run again if the map itself changes.
