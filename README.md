# Pooja Gosika: portfolio

Next.js, TypeScript, Tailwind CSS 4 and Motion.

## Run it

```
npm install
npm run dev
```

Then open http://localhost:3400.

## Change the content

Every word on the site is in `src/data/site.ts`. Project screenshots are in
`public/work`, and the profile photo is `public/pooja.jpg`.

## Visitor map

The map shows where the current visitor is, with a line to Hyderabad. That
part needs no setup.

To also show everyone who has visited, the site needs somewhere to keep the
list. It uses a free Upstash Redis database:

1. Create a database at https://upstash.com.
2. Copy its REST URL and REST token.
3. Add them on the host as `UPSTASH_REDIS_REST_URL` and
   `UPSTASH_REDIS_REST_TOKEN` (see `.env.example`).

Only a rounded position, city and country are saved. No IP address is stored.

The world map shapes are generated by `npm run world` into
`src/data/world.json`. It only needs to be run again if the map itself changes.
